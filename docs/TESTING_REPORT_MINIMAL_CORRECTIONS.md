# แก้เฉพาะ Testing Report ต้นฉบับ

อ้างอิง PDF ต้นฉบับ `InternFlow_DES424 Group Project (1).pdf` หน้า 21-33 และเทียบกับเว็บ Project/InternFlow ณ 3 พฤศจิกายน 2026 ไม่จำเป็นต้องเปลี่ยนโครงรายงานหรือรูปแบบเดิม

| จุด | สิ่งที่ควรแก้เฉพาะจุด |
| --- | --- |
| หน้า 21-22 ตาราง UAT | ACCEPT ต้องมีหลักฐานของเกณฑ์นั้น การแสดงฟอร์มหรือสคริปต์ผ่านไม่ได้แปลว่าการส่งข้อมูลจริงสำเร็จ ข้อที่ยังไม่ได้ทดสอบใช้ NOT TESTED; ข้อที่ยังไม่มีในเว็บแยกเป็น requirement ที่ไม่ผ่าน/ยังไม่ทำ |
| หน้า 21 ข้อ 7 | เอาการกรองตัวเลข stipend ออกจากพฤติกรรมที่อ้างว่ามี เว็บมีการค้นหาและตัวกรองรูปแบบงาน/หมวดหมู่ |
| หน้า 22 ข้อ 23 และหน้า 32 | เว็บมีรายงานประเมินที่พิมพ์ได้ แต่ไม่มีการบังคับผ่านชั่วโมงขั้นต่ำเพื่อออกใบรับรองที่ได้รับการรับรอง สคริปต์กำหนด 320/300 ชั่วโมงและสถานะ OFFICIALLY_CERTIFIED เอง จึงไม่ได้ตรวจระบบจริง |
| หน้า 23-24 Authentication | เคส invalid login ต้องตรวจข้อความผิดพลาดและไม่มี session; การรอคำว่า InternFlow ยังผ่านได้แม้ระบบไม่ตรวจรหัสผ่าน ส่วน role selection ต้องกดปุ่มและตรวจสถานะที่เลือกจริง การเปิดหน้า register ไม่ใช่การสมัครสำเร็จ และตัวแปร valid login ที่ประกาศไว้ยังไม่ได้ถูกใช้พิสูจน์ UAT ข้อนั้น |
| หน้า 25-32 Test Script | หลายกรณีเปรียบเทียบค่าที่เพิ่ง Set Variable เช่น REVIEWING/COMMITTED หรือบอกว่าไฟล์ถูกส่งไป S3 ด้วย Log To Console ต้องเปลี่ยนเป็นการทำ action แล้วตรวจ UI/API/ข้อมูลที่เกิดขึ้นจริง |
| หน้า 25, 27, 29, 32 รูปแบบโค้ด | ตัวแปรบางส่วนถูกแปลงเป็นรูปแบบสมการหรือถูกตัดบรรทัดใน PDF ควรคงข้อความ `${VARIABLE}` และ Robot continuation ที่รันได้ ใช้ไฟล์ .robot เป็นแหล่งต้นฉบับ |
| Test Results ของแต่ละหมวด | ภาพสีเขียวเดิมเป็นผลของสคริปต์เดิม ไม่ใช่หลักฐานของสคริปต์ที่แก้แล้ว ต้องรันใหม่ เปลี่ยนภาพผลตามจริง และใช้วันที่ของการรันครั้งนั้น ไม่แก้วันที่ของผลเก่าให้เหมือนผลใหม่ |

แนวทางแก้คงเดิม: ย่อหน้าเปิด → ตาราง UAT แบ่งหมวด → Robot Test → `<หมวด> - Test Script` → `<หมวด> - Test Results` พร้อมภาพผลจริง การเปิด/ปิด browser ยังอยู่ได้ แต่ไม่นับแทนหลักฐานการทำงานครบทุก requirement

ในรอบเตรียม cloud นี้ยังไม่ได้แก้ PDF เพิ่ม ผลทดสอบ cloud-preparation เป็นหลักฐานแยก ต้องปรับข้อความในรายงานเรื่อง deployment จาก “proposed” เป็นผลจริงหลังรัน AWS สำเร็จเท่านั้น
